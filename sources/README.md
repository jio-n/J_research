# 原典とローカルキャッシュ

取得した公式ページとWeb調査結果の全文キャッシュは、手元の調査継続用として保持し、公開リポジトリには含めていません。

- [cache_manifest.csv](cache_manifest.csv)：ローカルの相対パス、バイト数、SHA-256。キャッシュの所在と同一性を確認するための一覧です。
- 原典のURL、Evidence ID、確認日、該当箇所は `../data/research/report_v0/evidence_ledger.csv` 等のエビデンス台帳を参照してください。
- 出展社ごとの公式詳細URLと取得状況は `../data/exhibitors_2024_with_details.csv` と `../data/exhibitors_2026_with_details.csv` に保存しています。

元ページの本文・写真・画像の再利用許諾を表すものではありません。ローカルキャッシュのパスを含む分析データは保持しているため、GitHubから取得した環境ではそのパスのファイルが存在しない場合があります。
