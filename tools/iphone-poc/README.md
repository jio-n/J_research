# iPhone ローカル HTML 最小 PoC

正本仕様書の第 7・10・12 章に対応。`index.html` 1 ファイル、外部通信・外部ライブラリ・サーバー不要。架空サンプル 2 社は公式出展社ではない。

## 作成済み

- 企業名／ブース検索、企業メモ、件数制限を設けない個別アイテム。
- 事前候補の概要・理由・質問、展開式の詳細・差分・出典。実際に見た候補だけ明示操作で記録追加。
- localStorage 自動保存／再読込復元、失敗表示。添付も data URL として保存。
- 写真撮影の file input、写真・音声のファイル取込、画像表示・音声再生。
- MediaRecorder が利用可能な環境での録音。不可なら外部ボイスメモを取り込む。
- 添付込み JSON／非圧縮 ZIP バックアップ、本 PoC 出力からの復元。ZIP は records.json を格納し CRC32 を確認。一般の圧縮 ZIP の取込は対象外。
- 年度別マスター CSV／JSON 取込。企業名は name / company_name / exhibitor_name / company_name_ja / 企業名 / 出展社名、ブースは booth / booth_no / booth_number / ブース / 小間番号、年度は year / 年度（またはファイル名の 2024/2026）。JSON は配列または companies / exhibitors 配列。

## 制約・検証状態

- 2026-10-16: `node tools/iphone-poc/check.cjs` 成功。JS 構文、候補の明示追加、添付込み保存形式、ZIP 往復・破損検出、CSV 引用符だけを確認した。実ブラウザー UI・実機は対象外。
- iPhone の file:// 起動、永続保存、撮影、録音、再生、ダウンロード、終了後復元、ZIP 復元は **すべて実機未検証**。Mac / iPhone の動作済みとは主張しない。
- 件数はコード上無制限だが端末容量・メモリには上限あり。大きな添付で localStorage 容量を超えたら現在セッション内に保持し、保存失敗を表示する。直ちにバックアップが必要。ブラウザー終了で未保存データは失われる。
- localStorage は同じファイル名・場所でも環境によって使えない／消える可能性がある。バックアップを唯一の可搬データとして扱う。
- バックアップ復元は明示確認後に全置換。調査員間の統合・削除・自動名寄せはこの PoC の範囲外。
- 元データ保護のため削除操作は未実装。ファイル出力は JSON / ZIP のどちらも OS の保存先を利用者が確認する。
