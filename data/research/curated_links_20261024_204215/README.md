## 根拠と再作成

- `additional_sources.csv`：追加資料の発行者、該当節、本文の要約、適用範囲、確認日。原文引用ではなく調査者による要約。
- `link_plan.json`：新版の構造化データ、セル別のリンク計画、元ファイルのSHA256。
- `additional_link_checks.json`：追加10URLの接続確認。本文精読の代用とはしない。
- `native_verification.json`：Excel実機の保存・再読込、588セルの一致、色・寸法・フィルター・124リンクの検証。
- `package_verification.json`：保存XMLでリンク、エラーセル、固定表示、空欄、元ファイル不変を確認。
- `prepare.py` → `edit_workbook.mjs` → `verify_native.ps1` → `render_saved.mjs`：新版専用の作成・検証処理。`verify_package.py` と `check_additional_links.py` も同版に限定。

生成・編集はArtifact Toolを使用し、ネイティブのリンク・表範囲はExcelで設定。表示は保存後の4範囲を画像化して目視確認。自動折り返しに伴う行高変化と黄色の未読注記セルの色変化を検出し、元どおりに復元してから再検証した。

`_private/` は閲覧用の画像、取得ページ、実行依存関係でありGitHubへは追加しない。既存の調査や生成スクリプトは変更していない。
