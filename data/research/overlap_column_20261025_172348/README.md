企業単位で照合。Unicode表記、英字の大小・句読点、空白、法人格、括弧内の補足（WTA等）を正規化し完全一致で比較。ブース番号だけで同一企業としない。共通12社、AI側20アイテム行に重複表示。

追加指示を反映し、重複企業のAI側記入済み20レコードを自動化側へ転記。同一企業・同一ブースの空の候補行をアイテム別レコードへ置き換えた。HexagonはAI側E2013と元候補E7035でブースが異なるため、E7035の候補行を残してE2013の3レコードを追加した。サイバーRCのブース注記も原文どおり保持。自動化側は50社・59レコードで、重複表示は21行。全91レコードの照合根拠を `overlap_audit.csv`、転記元行を `link_plan.json` の `origins` と `copied_records` に記録。

元のAI側本文・質問・優先・タグ・追加資料を改変せず転記。旧C～H列は新D～I列へ移動。転記したレコードのリンクも継承。ユーザーコメント欄へ調査者の推薦は追加していない。

本文の正本は既存のJSON転記ではなく、元Excelに現在保存されているセル値。元Excelから読み直して構造化データへ反映し、転記先を照合した。ふりがな情報はセル本文に混入させない。

`pending_user_comments.json` にWintechへのユーザー評価と質問案を、最終統合待ちとして保存。今回のExcelにはまだ反映せず、今後のユーザーコメントとともに統合する。工具対象であること、測定フィードバックが比較的単純に感じられること、より高度なワーク加工制御があれば優先することを記録。主観評価と技術的に確認した事実を区別。
